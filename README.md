# yt-fzf

`fzf` を使ったターミナル向けの YouTube ダウンローダー / プレイヤーです。キーワード検索・URL 直接指定のどちらからでも、動画のストリーミング再生、動画保存、音声抽出ができます。手元の音声・動画ファイルの加工（時間指定・音量調整・形式変換）や、音楽CDへの書き込みもできます。ネオン風のカラーテーマで動く、マウス操作にも対応したメニューUIです。

## 特徴

- キーワード検索（YouTube 上位15件。設定ファイルで変更可）または URL 直接指定で動画を選択
- 検索結果から複数選んで、まとめて保存
- ストリーミング再生（`mpv` 使用）と、通信量の少ない音声のみ再生
- 動画保存（1080p / 720p はどの機器でも再生しやすい H.264 + AAC の MP4。最高画質も選択可）
- 音声保存（MP3 / M4A / BEST / WAV / FLAC。M4A と BEST は YouTube の音声を変換せずそのまま保存）
- 時間指定ダウンロード（`開始-終了` で範囲を切り出し）
- ライブ配信中・配信開始前の動画は保存しない（検索結果に `[LIVE]` / `[配信予定]` の印を表示。再生はできる）
- 音量正規化（ラウドネスを統一、EBU R128 系の `loudnorm` フィルタ。形式は元のまま）
- 完了時に保存したファイルのパスを表示。同名ファイルがあってスキップされた場合はそのことを表示
- 動画の URL 確認・クリップボードへの自動コピー
- 手元の音声・動画ファイルの加工（時間指定での切り出し、音量の正規化・上げ下げ、形式変換。複数ファイルをまとめて処理可）
- 手元のファイルの再生（加工したファイルをその場で聞いて確認できる）
- 音楽CD用の WAV への変換と、音楽CDへの書き込み（`cdrdao` なら日本語の曲名入り＝CD-Text）
- 保存先フォルダの選択・記憶（次回起動時も同じ場所を使用）
- 各メニューに「戻る」「終了」を用意（誤操作しても迷わない）

## 必要なもの

| コマンド | 用途 | 必須 |
|---|---|---|
| [`fzf`](https://github.com/junegunn/fzf) | メニューUIの表示・選択 | 必須 |
| [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) | 動画情報の取得・ダウンロード | 必須 |
| `ffmpeg` / `ffprobe` | 動画/音声の結合・変換・音量正規化 | 必須 |
| [`mpv`](https://mpv.io/) | ストリーミング再生 | 再生するときのみ |
| `cdrdao` | 音楽CDへの書き込み（曲名入り） | CD に書き込むときのみ（`sudo pacman -S cdrdao`。曲名なしでよければ `cdrecord`（`cdrtools`）/ `wodim` でも可） |

必須のコマンドは起動時に自動でチェックされ、不足していればエラーで終了します。`mpv` は再生を選んだときだけ確認するので、保存だけに使う場合は無くても動きます。

### クリップボードコピー（任意）

URL 確認機能で自動コピーを使う場合、以下のいずれかがあると便利です（無くても URL は画面に表示されます）。

- Wayland: `wl-clipboard`（`wl-copy`）
- X11: `xclip` または `xsel`
- macOS: `pbcopy`（標準搭載）

## インストール（Arch Linux）

### 方法1：パッケージとしてインストール（おすすめ）

`makepkg` でパッケージを作ってインストールします。`fzf`・`yt-dlp`・`ffmpeg` も pacman が自動で入れます。

```bash
sudo pacman -S --needed git base-devel
git clone https://github.com/yannsi/yt-fzf-sh.git
cd yt-fzf-sh
makepkg -si
```

再生も使う場合は `mpv` も入れてください。

```bash
sudo pacman -S --needed mpv
```

- **アップデート**：`yt-fzf-sh` フォルダで `git pull` してから、もう一度 `makepkg -si`
- **アンインストール**：`sudo pacman -R yt-fzf`

### 方法2：自分のホームフォルダにインストール（sudo 不要）

`~/.local/bin/yt-fzf` にコピーするだけの方法です。依存パッケージは自分で入れます（足りないものがあればインストール時に案内が出ます）。

```bash
sudo pacman -S --needed git fzf yt-dlp ffmpeg mpv
git clone https://github.com/yannsi/yt-fzf-sh.git
cd yt-fzf-sh
bash install.sh
```

- **アップデート**：`yt-fzf-sh` フォルダで `git pull` してから、もう一度 `bash install.sh`
- **アンインストール**：`bash install.sh uninstall`

`yt-fzf: command not found` になる場合は `~/.local/bin` が `PATH` に入っていません。`~/.bashrc` に次の1行を追加して、ターミナルを開き直してください。

```bash
export PATH="$HOME/.local/bin:$PATH"
```

### インストールせずに試す

```bash
git clone https://github.com/yannsi/yt-fzf-sh.git
cd yt-fzf-sh
bash yt-fzf.sh
```

### ほかのディストリビューション（Ubuntu / Debian）

依存パッケージを入れてから、方法2の `bash install.sh` でインストールできます（案内される pacman のコマンドは apt に読み替えてください）。

```bash
sudo apt update
sudo apt install git fzf mpv ffmpeg
# yt-dlp は配布バイナリを直接使うのがおすすめ（apt 版は古い場合が多い）
sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp
```

## 使い方

```bash
yt-fzf
```

ヘルプは `-h`（または `--help`）で表示できます。ツールが未インストールでもヘルプは表示されます。

```bash
yt-fzf -h
```

バージョンは、メニュー枠のタイトル（`[ YT-DOWNLOADER v1.2.1 ]` など）に表示されます。`-v`（または `--version`）でも確認でき、こちらは起動している本体の場所も表示します。

```bash
yt-fzf -v
```

起動するとメインメニューが表示されます。

```
SEARCH   キーワードで検索
URL      URLを入力
LOCAL    手元のファイルを加工（時間指定・音量・CD）
CONFIG   保存先を変更
EXIT     終了
```

- **SEARCH**：キーワードを入力すると YouTube 検索結果（上位15件）が一覧表示されます。動画を選ぶと操作メニューに進みます。`Tab` で複数選んで Enter を押すと、まとめて保存できます（下記）。検索自体が失敗した場合は、エラー内容が表示されます。ライブ配信中の動画には `[LIVE]`、配信開始前の動画には `[配信予定]` の印が付きます。
- **URL**：YouTube の URL を直接貼り付けて操作メニューに進みます。プレイリスト再生中の URL（`watch?v=…&list=…`）を貼っても、再生・保存されるのはその動画1本だけです（プレイリスト全体はダウンロードしません）。プレイリストそのものの URL（`playlist?list=…`）やチャンネルの URL は受け付けず、動画1本の URL を入れるよう案内が出ます。
- **LOCAL**：パソコンにある音声・動画ファイルを加工します。詳しくは「[手元のファイルの加工](#手元のファイルの加工local)」を参照してください。
- **CONFIG**：保存先フォルダを専用のフォルダブラウザで選択します（スペースを含むフォルダ名にも対応）。選んだ場所は `~/.yt-downloader/.last_dir` に保存され、次回起動時も引き継がれます。

動画を選ぶと、以下の操作メニューが表示されます。

```
STREAM   ストリーミング再生
LISTEN   音声のみ再生（通信量が少ない）
VIDEO    動画保存
AUDIO    音声保存
URL      URLを確認 / コピー
BACK     戻る
EXIT     終了
```

### 動画保存 / 音声保存の流れ

ライブ配信中の動画や配信開始前の動画は保存できません（配信中の動画を保存すると、配信が終わるまで録画し続けて終わらないためです）。保存を選んだ時点でその旨が表示され、メニューに戻ります。配信が終わってから保存してください。再生（STREAM）はできます。URL を貼った場合は、配信中かどうかの確認に数秒かかります。

1. **時間指定するか選択**
   - `FULL`：動画全体をダウンロード
   - `RANGE`：範囲を「開始-終了」の1行で入力（例: `0:00-1:00`、`1:20:00-1:25:30`）
     - 分:秒、時:分:秒、秒数のいずれでも指定できます
     - スペースや全角の `：` `〜` が混ざっていても自動で直します
     - 形式が正しくない場合や、終了が開始より前の場合は再入力を求められます
     - 範囲指定した場合、ファイル名に時間範囲が自動的に付与されます（例: `タイトル [0-00_1-00].mp3`）。全体版や他の切り抜きと名前が衝突してスキップされるのを防ぐためです。
2. **音量を正規化するか選択**
   - `YES` を選ぶと、`ffmpeg` の `loudnorm` フィルタ（目標 -16 LUFS）で音量をそろえます
   - MP3 / WAV / FLAC は、形式を変換するときに同時に正規化します（変換は1回だけ）。サンプルレートは 48kHz になります
   - M4A / BEST / 動画は、ダウンロード後に音声だけを再エンコードして正規化します。音質は AAC が 192kbps、Opus が 160kbps です。形式（拡張子）とサンプルレートは元のまま保たれます
   - 動画は映像を再エンコードしないため、画質の劣化はありません
   - 正規化に失敗した場合は、ダウンロードしたファイルがそのまま残ります
3. **画質 / 音声フォーマットを選択**して実行
   - `1080p / MP4`・`720p / MP4`：H.264（映像）+ AAC（音声）を優先して選びます。スマホや Windows の標準プレイヤーでもそのまま再生できます
   - `BEST`：4K などの最高画質を優先します。VP9 / AV1 になることが多く、再生できない機器があります

   音声フォーマットの違い:

   | 選択肢 | 保存のしかた | 向いている用途 |
   |---|---|---|
   | `MP3` | YouTube の音声を MP3（最高品質 VBR V0）に変換 | 古い機器・カーオーディオなど、どこでも再生したいとき |
   | `M4A` | YouTube の AAC 音声を変換せずそのまま保存（劣化なし） | iPhone・Mac・Windows で再生したいとき |
   | `BEST` | YouTube の最高音質の音声（ふつうは Opus）を変換せずそのまま保存（劣化なし） | 音質を最優先したいとき |
   | `WAV` / `FLAC` | 非圧縮・可逆圧縮に変換。音質は元と同じで、ファイルは約6倍の大きさ | 動画編集ソフトなどで WAV / FLAC が必要なとき |

   YouTube の音声はもともと圧縮されているため、WAV / FLAC にしても元以上の音質にはなりません。

いずれの段階でも `BACK` で一つ前の画面に戻れます。

処理が終わると、次のいずれかが表示されます。

| 表示 | 意味 |
|---|---|
| `[ 完了 ]` と保存先のパス | 保存に成功しました |
| 同じ名前のファイルが既にあるため、ダウンロードをスキップしました | 保存先に同名ファイルがあり、新しく作られませんでした（既存ファイルは変更されません） |
| ダウンロードに失敗しました | 直前に表示された yt-dlp のエラーを確認してください |

### ストリーミング再生

`yt-dlp` が動画を取得し、そのデータを `mpv` に流し込んでウィンドウで再生します。`Q` キーで再生を終了できます。

以前は `mpv` に URL を渡して `mpv` 側で取得させていましたが、YouTube の仕様変更により `HTTP error 403 Forbidden` で再生できないことがあるため、取得は `yt-dlp` に任せる方式にしています（v1.0.7〜）。

- **STREAM**：動画をウィンドウで再生します（最大 1080p）。読み込み済みの範囲内で早送り・巻き戻しができます（まだ読み込んでいない先へは飛べません）。
- **LISTEN**：音声だけを再生します。映像を取らないので通信量が少なく、音楽を聞くだけのときに向いています。

画質などは[設定ファイル](#設定ファイル)で変えられます。通信が10秒応答しない場合はタイムアウトします。

### まとめて保存

検索結果の一覧で `Tab` を押して複数の動画を選び、Enter を押すと、まとめて保存できます。

1. `VIDEO`（動画）か `AUDIO`（音声）を選びます
2. 音量正規化・画質（または音声形式）を1回だけ選ぶと、選んだすべての動画に同じ設定で保存します（時間指定はできません）
3. 1本ずつ順に保存し、最後に「保存できた本数 / うまくいかなかった本数」を表示します。ライブ配信中・配信開始前の動画は飛ばします

### 手元のファイルの加工（LOCAL）

YouTube からダウンロードしたものに限らず、パソコンにある音声・動画ファイル（MP3 / M4A / WAV / FLAC / Opus / MP4 / WebM / MKV など）を加工できます。**元のファイルは変更せず**、同じフォルダに名前を変えて保存します（例: `曲名 [0-10_0-40] [正規化].mp3`。同じ名前があれば `(2)` などの番号を付けます）。

1. **ファイルを選ぶ**
   - `LIST`：保存先フォルダ（サブフォルダは3階層まで）の音声・動画ファイルを一覧から選びます。新しいファイルが上に並びます。`Tab` で複数選べます（選んだ順が CD の曲順になります）
   - `PATH`：ファイルまたはフォルダの場所を入力します。ファイルマネージャからのドラッグ＆ドロップにも対応しています。フォルダを指定すると、そのフォルダの一覧から選べます
2. **操作を選ぶ**：`EDIT`（加工する）か `PLAY`（再生する）。再生では、選んだファイルを順に再生します（`>` / `<` で次 / 前のファイル）
3. **時間指定**（1ファイルを選んだときだけ）：動画保存と同じく `開始-終了` で範囲を切り出します。動画は位置を正確にするため映像を作り直します
4. **音量**
   - `NO`：変更しない
   - `NORM`：正規化（ほかの曲と音量をそろえる。YouTube 保存時と同じ設定）
   - `GAIN`：dB を指定して上げる・下げる（例: `3` で上げる、`-6` で下げる。6dB でおよそ2倍・半分の大きさ）。上げたときに音が割れないよう、大きすぎる部分だけ自動で抑えます
5. **保存の形式**
   - `SAME`：元の形式のまま（動画は動画のまま）
   - `MP3` / `M4A` / `WAV` / `FLAC`：音声だけを取り出して変換
   - `CDWAV`：音楽CDの規格（44.1kHz / 16bit / ステレオ）の WAV に変換します。保存先フォルダに `CD_日時` のフォルダを作り、`01 曲名.wav` のように曲順の番号を付けて保存します。ほかの書き込みソフトで CD を焼くときに使います
   - `CDBURN`：音楽CDに直接書き込みます（下記）

時間指定・音量・形式のどれも変えない場合は、ファイルを作りません。保存が終わると、作ったファイルをその場で再生して確認できます（`PLAY`）。

#### 音楽CDへの書き込み（CDBURN）

`cdrdao`（`sudo pacman -S cdrdao`）と CD ドライブが必要です。`cdrdao` を使うと、**曲名と CD のタイトルも書き込みます**（CD-Text。日本語にも対応。対応するカーナビ・CD プレーヤーで表示されます）。`cdrdao` が無く `cdrecord` / `wodim` がある場合は、曲名なしで書き込みます。

1. 書き込む曲と曲順、曲名、合計時間が表示されます。曲名はファイルのタグ（タイトル）を使い、無ければファイル名を使います。80 分（74 分を超える場合は 80 分の CD-R が必要）を超えると書き込めません
2. 空の CD-R をドライブに入れてから、`BURN`（書き込む）か `TEST`（試し書き：実際には書き込まずに動作だけ確認）を選びます
3. `cdrdao` のときは、CD のタイトル（アルバム名）を入力します。空のまま Enter を押すと「CD 日付」（例: `CD 2026-10-18`）になります
4. CD 用の WAV を一時フォルダ（`~/.cache/yt-fzf-cd.*`）に作り、曲間に余計な無音を入れずに書き込みます。終わるとディスクが出てきます。一時フォルダは自動で削除されます

CD-Text では、CD 全体とすべての曲にタイトルとアーティストが必要です。アーティストはファイルのタグを使い、無い曲は、ほかの曲のアーティストが1人ならその人、それ以外は「不明」にします。CD 全体のアーティストは、全曲が同じ人ならその人、複数なら「V.A.」です。

CD の規格で 4 秒未満の曲は書き込めないため、短い曲は後ろに無音を足して 4 秒にします。曲名に Shift_JIS で表せない文字（絵文字など）があれば、その文字は省きます。日本語の曲名の書き込みには `cdrdao` 1.2.5 以降が必要です（古い場合は曲名なしで書き込みます）。

書き込みに失敗するときは、表示されたメッセージを確認してください。使用済みの CD-R には書き込めません。CD-RW は先に消去が必要です。ドライブが複数あるときは、書き込むドライブを選ぶメニューが出ます。

### URL の確認 / コピー

操作メニューから選ぶと、選択中の動画の URL が画面に表示されます。クリップボードツールが使える環境では自動でコピーされます。

## 設定ファイル

`~/.yt-downloader/config` に書くと、次の設定を変えられます。初めて起動したときに、説明付きのひな形が作られます（変えたい行の先頭の `#` を消して書き換えます）。パッケージで入れた本体（`/usr/bin/yt-fzf`）は更新のたびに上書きされるため、本体ではなくこのファイルに書いてください。

| 項目 | 内容 | 標準の値 |
|---|---|---|
| `STREAM_FORMAT` | STREAM の画質（`yt-dlp -f` の書き方）。720p までなら `'bv*[height<=720]+ba/b'` | `'bv*[height<=1080]+ba/b'` |
| `LISTEN_FORMAT` | LISTEN（音声のみ再生）の形式 | `'ba/b'` |
| `SEARCH_COUNT` | 検索結果の件数（1〜50） | `15` |
| `CD_MAX_SECONDS` | 音楽CDに入る時間の上限（秒）。74 分の CD-R なら `4440` | `4800` |

このファイルはプログラムとして実行はせず、上の項目の「名前=値」だけを読み込みます。

## 保存先の記憶

保存先フォルダの選択内容は次の場所に保存されます。

```
~/.yt-downloader/.last_dir
```

このファイルを削除するか内容を書き換えれば、デフォルトの保存先（`~/Downloads`、存在しなければ `$HOME`）に戻せます。

## 出力ファイル名の規則

| 種類 | ファイル名テンプレート |
|---|---|
| 全体ダウンロード | `タイトル.拡張子` |
| 範囲指定ダウンロード | `タイトル [開始_終了].拡張子`（`:` は `-` に置換） |

Linux のファイル名は 255 バイトまでで、日本語は1文字3バイトです。そのため、タイトルが長い場合はファイル名に使う部分を自動で切り詰めます（全体ダウンロードは 200 バイト＝日本語で約66文字、範囲指定は 180 バイト＝約60文字まで）。文字の途中で切れることはありません。

同じ動画・同じ範囲を再度ダウンロードすると、yt-dlp の仕様上「同名ファイルが既に存在する」として新規作成がスキップされ、その旨が表示されます。作り直したい場合は、既存ファイルを削除・リネームしてから実行してください。

## 既知の制限

- `--download-sections`（時間指定ダウンロード）は YouTube 側の配信仕様変更の影響を受けやすく、`yt-dlp` が古いと失敗しやすくなります。時間指定を使う場合は `yt-dlp` を最新に更新しておくことを推奨します（`sudo pacman -Syu yt-dlp`（pacman で入れた場合。それ以外は `yt-dlp -U`））。
- 音量正規化は再エンコードを伴うため、M4A / BEST / 動画の音声は、正規化しない場合に比べてわずかに音質が変わります（MP3 はもともと変換するので、変換の回数は増えません。WAV / FLAC は劣化しません）。
- 動画の範囲指定では、切り出し位置を正確にするため、切り出した部分の映像を再エンコードします。そのぶん時間がかかります。
- `--flat-playlist` を使った検索では、投稿者名や再生時間が取得できない動画があります（その場合「不明」または空欄で表示されます）。

## トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 更新したのにメニューが変わらない／枠のタイトルにバージョンが出ない | 古い `yt-fzf` が別の場所に残っていて、そちらが起動しています。`type -a yt-fzf` で場所を確認し、古いもの（`~/.local/bin/yt-fzf` や旧パッケージ `yt-fzf-sh`）を削除してから入れ直し、`hash -r` を実行してください |
| `Server returned 403 Forbidden` | YouTube 側の仕様変更または `yt-dlp` が古いことが原因。`sudo pacman -Syu yt-dlp`（pacman で入れた場合。それ以外は `yt-dlp -U`） で更新してください。最新でも直らないときは、少し待つと yt-dlp 側の修正版が出ることが多いです |
| 再生時に `[ffmpeg] https: HTTP error 403 Forbidden` と出て再生できない | v1.0.6 以前の再生方式の問題です。v1.0.7 以降に更新してください |
| 「ダウンロードをスキップしました」と表示される | 保存先に同名ファイルがあります。表示されたパスのファイルを削除・リネームしてから再実行してください |
| 「検索に失敗しました」と表示される | 表示されたエラーを確認してください。多くの場合 yt-dlp の更新で直ります |
| 「再生には mpv が必要です」と表示される | `mpv` をインストールしてください |
| 「CD の書き込みには cdrdao（または cdrtools）が必要です」と表示される | `sudo pacman -S cdrdao` でインストールしてください |
| CD に曲名が表示されない | 曲名（CD-Text）の書き込みには `cdrdao` が必要です。また、CD-Text に対応していない機器では表示されません |
| 「CD ドライブが見つかりません」と表示される | ドライブがつながっているか確認してください（`/dev/sr0` などとして認識されている必要があります） |
| 「ディスクが入っていないか、読み取れません」と表示される | 空の CD-R を入れて、ドライブが読み込み終わるまで数秒待ってからやり直してください |
| `ffmpeg` / `ffprobe` が見つからないというエラー | `ffmpeg` をインストールしてください（`ffprobe` も同梱されています） |
| クリップボードにコピーされない | `xclip` / `xsel` / `wl-clipboard` のいずれもインストールされていません。画面に表示された URL を手動でコピーしてください |

## 設定ファイル / 一時ファイル

| パス | 内容 |
|---|---|
| `~/.yt-downloader/.last_dir` | 最後に選んだ保存先フォルダ |
| `~/.yt-downloader/config` | 設定ファイル（[設定ファイル](#設定ファイル)を参照） |
| `$(mktemp)` で作成される一時ファイル | 検索結果・エラー出力・保存先パスなどの一時保持用。終了時に自動削除されます |
| `~/.cache/yt-fzf-cd.*` | 音楽CDに書き込む WAV の一時フォルダ。書き込み後・終了時に自動削除されます |
