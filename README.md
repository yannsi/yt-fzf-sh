# yt-fzf-sh

Interactive YouTube downloader and streamer using `fzf` and `yt-dlp`.

This is an Arch Linux package for the `yt-fzf.sh` script.

## Dependencies

- `bash`
- `fzf`
- `yt-dlp`
- `mpv`
- `ffmpeg`

## Installation (Arch Linux)

```bash
git clone https://github.com/yannsi/yt-fzf-sh
cd yt-fzf-sh
makepkg -si
```

## Usage

```bash
yt-fzf
```
